TWD PROYECT — Reto Web

Proyecto desarrollado como parte del reto TDW (JL) - Tecnología Digital Web, cuyo objetivo es reconocer tecnologías para el desarrollo de aplicaciones web mediante una página básica hecha con Python, Flask, HTML, CSS, JavaScript y Tailwind CSS.

📋 Descripción
La aplicación es una página web simple que demuestra 3 acciones dinámicas realizadas con JavaScript puro, estilizada con Tailwind CSS y servida a través de un backend en Flask.

🚀 Tecnologías utilizadas
Python 3 — lenguaje base del proyecto
Flask — framework backend para servir la aplicación
HTML5 — estructura de la página
Tailwind CSS — estilos y diseño responsivo
JavaScript — lógica dinámica del lado del cliente

⚙️ Funcionalidades
Mostrar mensaje → al hacer clic, se genera y muestra un mensaje dinámico en pantalla.
Cambiar contenido → reemplaza el texto de un párrafo existente.
Modificar estilo → cambia las clases CSS (color de fondo, borde y escala) de un elemento al hacer clic.
